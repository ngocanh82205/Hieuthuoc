Thư mục lưu:

Hệ thống tự sao lưu lúc 2h30 sáng mỗi ngày và giữ 7 bản gần nhất. Nên tải bản sao lưu về máy khác định kỳ.

Khôi phục (H2):

  1. Dừng ứng dụng, đổi tên thư mục data/ (giữ lại phòng khi cần).
  2. Giải nén file .zip để lấy file .sql.
  3. Chạy: java -cp h2*.jar org.h2.tools.RunScript -url jdbc:h2:file:./data/hieuthuoc -user sa -script vinapharma_....sql
  4. Chạy lại ứng dụng.

Với MySQL:

mysqldump -u root -p hieuthuoc | gzip > vinapharma.sql.gz
